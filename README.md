# QuizHub Microservices

A production-ready Quiz Platform built using Java Microservices.

---

## Tech Stack

### Backend

- Java 21
- Spring Boot
- Spring Cloud

### Database

- PostgreSQL

### Messaging

- Apache Kafka

### Cache

- Redis

### Infrastructure

- Docker
- Docker Compose

### Monitoring

- Prometheus
- Grafana
- Zipkin

### Frontend

- React

---

## Architecture

- Config Server
- Eureka Discovery Server
- API Gateway
- Auth Service
- Quiz Service
- Question Service
- Submission Service
- Result Service
- Notification Service
